# Changelog

## 0.9.0-beta.1

Primeira beta publica do `FlockGit`.

### Destaques

- comando principal `flockgit` com suporte a `status`, `update` e `change`
- suporte a multiplos repositorios via arquivo `config`
- instalacao e desinstalacao para macOS e Linux
- autocomplete para `zsh` e `bash`
- `status` com estado local e sincronizacao com upstream
- `change` com suporte a branch local e remota
- `update` usando o upstream real da branch atual
- `--summary` como resumo opcional por comando
- testes automatizados em `tests/`

### Observacoes da beta

- suporte oficial para macOS e Linux
- uso recomendado em `zsh` e `bash`
- instalacao em `~/.flockgit` com setup silencioso via `aliases.sh`
- feedback de UX, install e autocomplete ainda faz parte do ciclo de refinamento
